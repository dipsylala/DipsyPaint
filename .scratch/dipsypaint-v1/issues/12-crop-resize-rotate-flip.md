# 12: Crop, resize, rotate 90°/180°, flip

**What to build:** The user can crop to a selection, resize the image/canvas, rotate in 90° and 180° steps, and flip horizontally/vertically, as in reference Paint. Spec: user story 6, AC8.

**Blocked by:** 10 (Rectangle selection)

**Status:** ready-for-agent

- [x] Crop to selection, resize, rotate 90°/180° and flip behave as in reference Paint
- [x] Resizing beyond 16384 px on either side is refused with a message
- [x] Each operation is undoable
- [x] Golden images for each operation
