# 23: Freeform rotate and skew

**What to build:** The user can rotate selections, shapes and text to any angle and skew them, as in reference Paint. Spec: user story 19.

**Blocked by:** 21 (Free-form selection, select all, invert, transparent selection), 20 (Text tool)

**Status:** ready-for-agent

- [x] Freeform rotation (any angle) of selections, shapes and text behaves as in reference Paint
- [x] Skew behaves as in reference Paint
- [x] Each transform is undoable
- [x] Golden images at arbitrary angles and skews
